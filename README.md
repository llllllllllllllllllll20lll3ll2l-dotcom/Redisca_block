# Redisca_block

Нативное приложение для Android 10+ (API 29+) с локальной VPN-фильтрацией DNS. Включите защиту и подтвердите системный запрос VPN. Список приложений задаёт, чей трафик направляется через VPN; после изменения списка включённая защита перезапускается. Пустой список означает, что выбраны все приложения.

Приложение перехватывает обычные DNS-запросы через локальный VPN, блокирует имена из небольшого встроенного списка и пересылает остальные запросы на DNS-сервер Cloudflare (1.1.1.1). DNS-запросы не остаются исключительно на устройстве. Приложение не использует VPN-сервер и не перехватывает содержимое HTTPS.

Это не блокировка всей рекламы: встроенная реклама, DNS-over-HTTPS, зашифрованный DNS и запросы напрямую к IP могут обойти фильтр. Частный DNS Android может мешать фильтрации. Только одна VPN может работать одновременно. Список доменов — стартовый, а не полный. Статистика считает заблокированные DNS-запросы, а не показы рекламы; Android не всегда позволяет определить приложение-источник, поэтому часть запросов отображается как «Неизвестное приложение». Статистика локальная и сбрасывается кнопкой на экране.

## Сборка APK

Установите JDK 17, Android SDK с платформой 35 и Gradle 8.9, затем выполните `gradle assembleDebug`. APK: `app/build/outputs/apk/debug/app-debug.apk`. GitHub Actions также собирает debug APK и прикладывает его к запуску workflow как артефакт. Для публикации требуется собственная подписанная release-сборка. Разрешение QUERY_ALL_PACKAGES используется для отображения списка приложений и может требовать обоснования при публикации в Google Play.
