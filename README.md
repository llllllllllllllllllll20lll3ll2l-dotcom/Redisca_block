# Redisca Block — убрать границы высоты постройки

Мод для **Minecraft 26.3** (Java Edition, «Wilderness Bound») на **Forge 66.x**,
который снимает верхний и нижний пределы высоты постройки во всех измерениях.

* Без лимита сверху (`Y = 319` ванильного потолка, плюс борт над ним).
* Без лимита снизу (`Y = -64` ванильного дна).
* Стандартный пакет: никаких новых блоков, предметов или сущностей.

> ⚠️ До 26.3 ваниль всё ещё ограничивает потолок высоты. После установки мода
> блоки можно ставить на любую высоту внутри того, что ваниль умеет представлять
> (см. ниже про жёсткий предел в 4064 блока).

---

## Что делает мод

В Minecraft 26.3 вся вертикальная модель игры (мин. и макс. высота блока, число
секций, битность карты высоты, кодирование секций, высота у клиента) вычисляется
из **двух методов** одного объекта — `DimensionType.minY()` и `DimensionType.height()`.
Мод переопределяет ровно эти два значения кодом внутрь миксина:

| Параметр | Ваниль (26.3) | После мода |
|---|---|---|
| Нижний лимит (`min_y`) | `-64` | `-2032` (максимум ванильной модели) |
| Верхний лимит блока (`min_y + height - 1`) | `319` (build limit `320`) | `2031` (build limit `2032`) |
| Общая высота (`height`) | `384` блока | `4064` блока (максимум модели) |
| Секции в чанк-сторе | `24` | `254` |
| Битность высотного маппинга | `9` бит | `12` бит |

Каждая из измерений (Overworld, Overworld Caves, Nether, End и **любые
пользовательские измерения**, включая кастомные измерения от модов) получает эту
высоту автоматически — без отдельной настройки.

### Честные оговорки

- **Жёсткий потолок в 4064 блока.** Это не техническое ограничение мода, а
  жёсткий предел самой ванильной модели: ось Y кодируется `BITS_FOR_Y = 12` бит
  (`Y_SIZE = 4096 - 32 = 4064`, `MAX_Y = 2031`, `MIN_Y = -2032`). Больше нельзя —
  и мод этого не пытается. Если игрок ставит блоки выше 2031, игра не сможет
  представить такой мир.
- **Ограничение логической высоты не трогаем.** `logical_height` — это
  отдельное ванильное значение («максимальная высота, на которую порталы и
  лакомства-кустхара могут доставить игрока»), а не лимит постройки. Мод его
  **не** меняет сознательно: ванильные значения `384 / 128 / 256 / 384`
  (Overworld / Nether / End / Overworld Caves) остаются. Если нужно — тоже
  можно переопределить, но это уже другое поведение.
- **Память и производительность.** Мир стал в 10 раз выше (4064 вместо 384
  блоков): каждый чанк держит 254 секции вместо 24. Ваниль при этом не ломается,
  но сервер и PC грузятся сильнее.
- **Блоки в существующих мирах не теряются.** Секции кодируются абсолютным Y
  в byte-массиве (старый мир продолжает читаться корректно), а вне пределов
  новый мир просто создаётся под расширенную модель.

## Требования

- **Java 25** (26.3 требует его минимум; сборка мода тоже использует Toolchain 25).
- **Minecraft 26.3**
- **Forge 66.1.x** (последний на 26.3 на момент написания — `66.1.9`)
- **Gradle 9.x** — установится автоматически через встроенный wrapper
  (`./gradlew`); требуется доступ к `services.gradle.org`,
  `maven.minecraftforge.net` и `repo.maven.apache.org`.

## Сборка

```bash
./gradlew build        # Windows: gradlew.bat build
```

Готовый мод окажется в `build/libs/redisca_block-1.0.0.jar`.

Чтобы увидеть смену версий Forge (например, если в `gradle.properties` будет
старое значение), отредактируйте `forge_version`. Минимум для Forge 26.3 — `66.0.0`.

Топ-три задачи:

| Задача | Описание |
|---|---|
| `./gradlew build` | сборка мода (jar + проверка) |
| `./gradlew runClient` | запуск в режиме клиента для отладки |
| `./gradlew runServer` | запуск в режиме сервера для отладки |

> ⚠️ **Важно (проверено в этом окружении):** сборка не удалось выполнить в самом
> песочнице — там нет Java с компилятором, а также закрыт доступ к
> `maven.minecraftforge.net`, `repo.maven.apache.org` и `services.gradle.org`
> (туда скачиваются Minecraft, Forge и Gradle). Всё перечислено выше — запуск
> `./gradlew build` должен работать на машине с нормальным доступом в интернет.

## Установка

1. Скачайте `maven`-сборку Minecraft 26.3 + Forge 66.1.9 (или новый).
2. Положите собранный `redisca_block-1.0.0.jar` в папку `mods/`.
3. Запустите игру. Блоки стартуют на полную высоту.

## Как это устроено

1. `META-INF/mods.toml` объявляет мод + `modId = "redisca_block"` и зависимость
   `forge` (`[66,)`) + `minecraft` (`[26.3,)`).
2. `redisca_block.mixins.json` регистрирует миксин
   `ru.redisca.block.mixins.DimensionTypeMixin`.
3. `DimensionTypeMixin` перехватывает `DimensionType.minY()` и `.height()`
   через `@Inject(HEAD, cancellable)`. Всё остальное (секции, высотный маппинг,
   кодирование секций, симуляция клиента) автоматически следует из этих двух
   значений.
4. `build.gradle` регистрирует `MixinConfigs` в манифесте JAR, а в режиме
   разработки пропускает `--mixin.config=redisca_block.mixins.json` в аргументах запуска.

### Ключевые константы

| Константа | Значение | Объяснение |
|---|---|---|
| `Limits.MIN_Y` | `-2032` | низкий предел ванильной модели (`minY % 16 == 0`) |
| `Limits.HEIGHT` | `4064` | полная высота ванильной модели (`4064 % 16 == 0`) |

Изменить верхнюю или нижнюю границу можно в `Limits.java`. Все значения —
делители 16 и обязательно `min_y + height <= 2032`, иначе будут выброшены
проверки `DimensionType`.

## Структура проекта

```
Redisca_block/
├── build.gradle                      # ForgeGradle 7.x, toolchain Java 25
├── settings.gradle                   # root project + foojay toolchain resolver
├── gradle.properties                 # minecraft_version / forge_version / mod_id
├── gradlew / gradlew.bat             # Gradle wrapper (Gradle 9.3.1)
├── gradle/wrapper/
├── src/main/java/ru/redisca/block/
│   ├── RediscaBlock.java             # @Mod — точка входа
│   ├── Limits.java                   # MIN_Y и HEIGHT (значения, выносимые для настройки)
│   └── mixins/
│       └── DimensionTypeMixin.java   # единственный миксин мода
├── src/main/resources/
│   ├── META-INF/mods.toml            # метаданные мода
│   └── redisca_block.mixins.json     # регистрация миксина
└── README.md (этот файл)
```

## Совместимость

- Minecraft 26.3 (зафиксировано в `gradle.properties`, `forge_version` можно
  менять).
- Forge 66.x.
- Работает в single player, на сервере и в мультиплеере.
